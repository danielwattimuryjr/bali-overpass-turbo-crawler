# Data Model — `public.streets`

## 1. Schema (fixed)

```sql
CREATE TABLE public.streets (
    uuid UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    osm_way_id BIGINT NOT NULL UNIQUE,
    name VARCHAR(150),
    coordinates GEOMETRY(LINESTRING, 4326) NOT NULL,
    dt_created TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    dt_updated TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

## 2. OSM → Column Mapping

| Column        | Source                            | Rules                                                                                                              |
| ------------- | --------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `uuid`        | —                                 | Generated by the DB (`gen_random_uuid()`), never set by the crawler. Stable across runs because upserts are keyed on `osm_way_id`. |
| `osm_way_id`  | `element.id` (type `way`)         | Natural key; the `ON CONFLICT` target.                                                                             |
| `name`        | `tags.name`                       | Trimmed; empty → `NULL`; > 150 characters → truncated to 150 + warning. No `name:id`/`ref` fallback.               |
| `coordinates` | `element.geometry[]` (`out geom`) | `LINESTRING(lon lat, ...)`, SRID 4326, 7 decimals. Ways with < 2 unique points are skipped.                        |
| `dt_created`  | —                                 | Defaults to `NOW()` on first insert; never changed.                                                                |
| `dt_updated`  | —                                 | `NOW()` on insert, and when an upsert detects a `name`/geometry change.                                            |

**Row filter:** ways with `highway` ∈ {`motorway`, `trunk`, `primary`, `secondary`, `tertiary`, `motorway_link`, `trunk_link`, `primary_link`, `secondary_link`, `tertiary_link`, `unclassified`, `residential`, `living_street`, `service`, `road`}, `area != yes`, inside the Bali Province area.

## 3. Migration File

`supabase/migrations/20261120000000_create_streets.sql`

```sql
-- PostGIS (in Supabase, extensions live in the "extensions" schema)
CREATE EXTENSION IF NOT EXISTS postgis WITH SCHEMA extensions;

CREATE TABLE IF NOT EXISTS public.streets (
    uuid UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    osm_way_id BIGINT NOT NULL UNIQUE,
    name VARCHAR(150),
    coordinates GEOMETRY(LINESTRING, 4326) NOT NULL,
    dt_created TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    dt_updated TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

COMMENT ON TABLE  public.streets IS 'Jalan kendaraan Provinsi Bali dari OpenStreetMap (via Overpass lokal).';
COMMENT ON COLUMN public.streets.osm_way_id  IS 'OSM way id';
COMMENT ON COLUMN public.streets.coordinates IS 'Geometri way, LINESTRING WGS84 (lon lat)';

-- Spatial index
CREATE INDEX IF NOT EXISTS streets_coordinates_gix
    ON public.streets USING GIST (coordinates);

-- Name search index (optional, for ILIKE/prefix)
CREATE INDEX IF NOT EXISTS streets_name_idx
    ON public.streets (name);

-- dt_updated trigger for manual updates outside the crawler
CREATE OR REPLACE FUNCTION public.set_dt_updated()
RETURNS TRIGGER
LANGUAGE plpgsql
SET search_path = ''
AS $$
BEGIN
    IF NEW.name IS DISTINCT FROM OLD.name
       OR extensions.ST_AsEWKB(NEW.coordinates) IS DISTINCT FROM extensions.ST_AsEWKB(OLD.coordinates)
    THEN
        NEW.dt_updated := NOW();
    END IF;
    RETURN NEW;
END;
$$;

DROP TRIGGER IF EXISTS streets_set_dt_updated ON public.streets;
CREATE TRIGGER streets_set_dt_updated
    BEFORE UPDATE ON public.streets
    FOR EACH ROW EXECUTE FUNCTION public.set_dt_updated();

-- Row Level Security: public read, writes only by the postgres role (crawler)
ALTER TABLE public.streets ENABLE ROW LEVEL SECURITY;

DROP POLICY IF EXISTS "streets are readable" ON public.streets;
CREATE POLICY "streets are readable"
    ON public.streets FOR SELECT
    TO anon, authenticated
    USING (true);
```

Notes:

- The migration uses `extensions.ST_AsEWKB` to compare geometries explicitly. This is needed because, with `SET search_path=''`, PostgreSQL/local Supabase does not resolve the geometry `=` operator directly. The crawler itself still sets `dt_updated` explicitly in its upsert and only updates rows that changed.
- The `COMMENT ON` texts are stored in the database itself and are left in their original language so the migration file stays identical to what has already been applied.
- If a public read policy is not wanted, remove the `CREATE POLICY` block; the data stays accessible via `service_role`/SQL.
- Supabase cloud includes `extensions` in the default `search_path`, so the `GEOMETRY` type and `ST_*` functions resolve without a prefix.

## 4. Row Lifecycle

```
         run N: way seen & not present yet  ──► INSERT (dt_created = dt_updated = NOW())
         run N: way seen & unchanged        ──► no change (no write)
         run N: way seen & changed          ──► UPDATE name/coordinates, dt_updated = NOW()
         run N: way not seen                ──► left as is (default)
                                                DELETE if CRAWLER_PRUNE=true & the run fully succeeded
```

## 5. Usage Examples

```sql
-- Find roads by name
SELECT osm_way_id, name FROM public.streets WHERE name ILIKE 'Jalan Raya Ubud%';

-- Roads within 500 m of a point (lon, lat)
SELECT osm_way_id, name
FROM public.streets
WHERE ST_DWithin(coordinates::geography,
                 ST_SetSRID(ST_MakePoint(115.2625, -8.5069), 4326)::geography, 500);

-- Total length of named roads (km)
SELECT name, ROUND(SUM(ST_Length(coordinates::geography))::numeric / 1000, 2) AS km
FROM public.streets WHERE name IS NOT NULL
GROUP BY name ORDER BY km DESC LIMIT 20;

-- Export one road as GeoJSON
SELECT ST_AsGeoJSON(coordinates) FROM public.streets WHERE osm_way_id = 123456;
```

## 6. Validation Queries

Run after a crawl (Supabase Studio → SQL Editor, or `psql`).

```sql
-- 1. Row count & share of unnamed roads
SELECT COUNT(*) AS total,
       COUNT(*) FILTER (WHERE name IS NULL) AS unnamed
FROM public.streets;

-- 2. Invalid geometry / wrong SRID / < 2 points  → must be 0
SELECT COUNT(*) FROM public.streets
WHERE NOT ST_IsValid(coordinates)
   OR ST_SRID(coordinates) <> 4326
   OR ST_NPoints(coordinates) < 2;

-- 3. Rows outside the Bali bounding box (with a small margin) → must be 0
SELECT osm_way_id, name FROM public.streets
WHERE NOT ST_Intersects(coordinates, ST_MakeEnvelope(114.35, -9.00, 115.80, -7.95, 4326));

-- 4. Duplicate osm_way_id → must be 0 (guaranteed by UNIQUE)
SELECT osm_way_id, COUNT(*) FROM public.streets GROUP BY 1 HAVING COUNT(*) > 1;

-- 5. Simple distribution per area (check for suspicious empty areas)
SELECT ROUND(ST_X(ST_Centroid(coordinates))::numeric, 1) AS lon,
       ROUND(ST_Y(ST_Centroid(coordinates))::numeric, 1) AS lat,
       COUNT(*)
FROM public.streets GROUP BY 1, 2 ORDER BY 1, 2;

-- 6. Rows changed in the last run
SELECT COUNT(*) FROM public.streets WHERE dt_updated > dt_created
  AND dt_updated > NOW() - INTERVAL '1 day';
```

Cross-check against Overpass (the count must equal `waysUnique` in the crawler log; `waysUnique` already includes ways that were later `skipped`, so the DB/file row count = `waysUnique − skipped`):

```
[out:json][timeout:300];
rel["boundary"="administrative"]["admin_level"="4"]["name"="Bali"];
map_to_area->.bali;
way["highway"~"^(motorway|trunk|primary|secondary|tertiary|motorway_link|trunk_link|primary_link|secondary_link|tertiary_link|unclassified|residential|living_street|service|road)$"]["area"!="yes"](area.bali);
out count;
```

## 7. JSON Output File Format

Used when `OUTPUT_MODE=json`. A single UTF-8 file (no BOM), default `./output/bali-streets-<YYYYMMDDTHHmmssZ>.json`.

### 7.2 Field Rules

| Field                     | Type                 | Rules                                                                                            |
| ------------------------- | -------------------- | ------------------------------------------------------------------------------------------------ |
| `streets`                 | array                | Unique per `osm_way_id`, **sorted ascending** by `osm_way_id`. Always written before `meta`.     |
| `streets[].osm_way_id`    | integer              | OSM way ID (= `osm_way_id` column).                                                              |
| `streets[].name`          | string \| null       | Same rules as the `name` column (trimmed, empty → `null`, max 150 characters).                   |
| `streets[].coordinates`   | GeoJSON `LineString` | `[lon, lat]`, 7 decimals, ≥ 2 unique points (= `coordinates` column).                            |
| `meta.format_version`     | integer              | Incremented when the file structure changes incompatibly.                                        |
| `meta.osm_base_timestamp` | ISO-8601 string      | From `osm3s.timestamp_osm_base` in the Overpass response (age of the OSM data).                  |
| `meta.count`              | integer              | Must equal the length of `streets`.                                                              |
| `meta.tiles_failed`       | integer              | > 0 means the file is **partial** (crawler exit 3).                                              |

The `uuid`, `dt_created`, `dt_updated` columns are **not** in the file because the DB generates them.

### 7.4 File Validation

With Node (on the host, from the repo root):

```powershell
node -e "const d=require('./output/'+process.argv[1]);const s=d.streets;let ok=s.length===d.meta.count;for(let i=1;i<s.length;i++)if(s[i].osm_way_id<=s[i-1].osm_way_id){ok=false;break}console.log({count:s.length,meta:d.meta.count,sortedUnique:ok,tilesFailed:d.meta.tiles_failed})" bali-streets-20261120T080000Z.json
```

For very large files, use a streaming tool (e.g. `jq --stream`) instead of loading the whole file.

### 7.5 Relationship to the Table

The mapping to the table columns is 1:1, so the file can be loaded later, for example:

```sql
-- concept: :streets_json = contents of the "streets" array
INSERT INTO public.streets (osm_way_id, name, coordinates)
SELECT (s->>'osm_way_id')::bigint,
       s->>'name',
       ST_SetSRID(ST_GeomFromGeoJSON(s->'coordinates'), 4326)
FROM jsonb_array_elements(:'streets_json'::jsonb) AS s
ON CONFLICT (osm_way_id) DO NOTHING;
```

An official import command is not in scope yet (see PRD §14).
